# 🚢 Titanic Survival Prediction Web App

A machine learning-based web application built with **Django** that predicts the survival of passengers on the Titanic using **Scikit-learn**, **NumPy**, **Pandas**, and **Matplotlib**.

![Titanic](https://upload.wikimedia.org/wikipedia/commons/f/fd/RMS_Titanic_3.jpg)

## 🔍 Overview

This project is a complete ML pipeline and deployment example. It includes:
- Data analysis and preprocessing using **Pandas**
- Visualization using **Matplotlib**
- Machine learning model building with **Scikit-learn**
- A user-friendly **Django** web interface for predictions

## 💡 Features

- Upload passenger details to predict survival
- Visualize dataset statistics and charts
- Train & test multiple ML models (Logistic Regression, Random Forest, etc.)
- Deployed locally or on cloud platforms (Heroku, Render, etc.)

## 🧠 Machine Learning

- **Model Used:** Logistic Regression (extendable to others)
- **Accuracy:** ~80% with cross-validation
- **Preprocessing:**
  - Handling missing values
  - Encoding categorical variables
  - Feature scaling

## 📊 Data Visualization

- Survival distribution
- Gender-based survival analysis
- Class-based survival analysis
- Heatmaps for feature correlation

## 🛠️ Tech Stack

| Component     | Technology        |
|---------------|-------------------|
| Backend       | Django             |
| ML & Data     | Pandas, NumPy, Scikit-learn |
| Visualization | Matplotlib         |
